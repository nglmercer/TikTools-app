插件打包、签名与注册表 ​

目标与前置条件 ​

分发可独立检查字节、发布者权限和宿主兼容性的包。从已验证插件和受支持目标开始。签名需要保存在仓库之外的作者私钥；注册表根委托是独立的运维职责。

准备可审查的归档 ​

sh
tiktools-plugin validate --publish
tiktools-plugin build --release
tiktools-plugin keygen --id acme-1 --publisher acme --out /private/path/keys

build 编译包并创建 .plugin 归档。清单入口、资源、语言文件、UI 输出及相关运行时依赖，连同 checksums.json 一起打包。native/process 构建需要兼容的目标产物；纯 JavaScript 包保持可移植，直到原生扩展或平台设施对其施加限制。

对已有构建归档，请使用确切文件路径，不要使用未经审查的通配符：

sh
tiktools-plugin sign dist-plugin/acme.hello-0.1.0.plugin --key /private/path/keys/acme-1.key.json
tiktools-plugin verify dist-plugin/acme.hello-0.1.0.plugin --trust /private/path/keys/acme-1.pub.json

将归档名替换为本次构建实际生成的目标特定输出。签名覆盖校验和，校验和覆盖包文件。公钥可以分享；私钥文件不得进入版本控制或日志。

信任与更新策略 ​

静态注册表协议具有根签名权限及委托的索引/发布者密钥。发布者命名空间批准不等于包完整性，Cloud 目录摘要也不能替代任何一条签名链。解析器检查通道、引擎、schema/协议/ABI、运行时及目标。即使文件哈希匹配，已撤回、已吊销或不兼容发行版也不具备资格。

宿主安装前先显示审查。自动更新要求策略允许、包未固定、签名发布者兼容且没有新增权限；扩大权限必须审查。产品 Cloud 目录安装不同于底层静态注册表编写，常规产品流程拒绝任意远程包 URL。

预期结果、恢复与验证 ​

安装器可在应用已审查包之前验证字节，并保留回滚/恢复状态。开发暂存不属于安装器管理。信任失败时，修复委托或发布者元数据，不要将未签名覆盖标志作为常规分发策略。运行时启动不确定时，停止替换并协调确认保留的结果。

使用 bun scripts/task.ts rust test -p tiktools-plugin-package --locked 和注册表测试验证离线夹具。包验证器及注册表模型负责技术格式；发布基础设施需要单独运维验收。

运行细节 ​

应判断验证 JSON，而不只是进程退出码。verify 可在 signature.status 为 unsigned 或 untrusted 时成功退出。只有状态为 verified，且包 ID、发布者和 key ID 均符合预期时才接受，再检查分发策略。本地 --trust 只证明与该本地信任键的签名关系，不证明注册表委派或命名空间授权。单独的校验和不证明发布者权限或更新器信任。以下自动判断必须拒绝任何意外结果。

sh
tiktools-plugin verify dist-plugin/acme.hello-0.1.0.plugin --trust /private/path/keys/acme-1.pub.json > verification.json
bun -e 'const r = await Bun.file("verification.json").json(); if (r.signature?.status !== "verified" || r.id !== "acme.hello" || r.signature.publisher !== "acme" || r.signature.keyId !== "acme-1") throw new Error("Package trust did not match policy");'

命令行操作 ​

本指南中的每个操作也可通过 CLI 使用——离线、可编写脚本、适合代理。用法行是解析器语法,在所有语言中保持英文。

命令摘要
tiktools publisher list列出发布者命名空间
tiktools publisher create <namespace>创建发布者命名空间
tiktools publisher delete <namespace-or-publisher-id>删除命名空间或发布者 破坏性
tiktools publisher keys <publisher-id>列出发布者的签名密钥
tiktools publisher enroll <publisher-id> [--key-id <id>]登记发布者密钥；从 stdin 读取后端密码
tiktools publisher upload <publisher-id> <path>上传插件包
tiktools publisher submit <upload-id> <publisher-key-id> <plugin-id> <version> [--target any]提交上传以供审核
tiktools publisher release <release-id>创建发布
tiktools publisher publish <release-id>发布一个 release
命令摘要
tiktools registry list列出已配置的注册表
tiktools registry refresh刷新注册表元数据
tiktools registry package <id>显示一个注册表软件包
tiktools registry cloud-catalog [--query q] [--after cursor] [--generation value] [--target name]搜索云目录
tiktools registry cloud-summaries [--query q] [--cursor value] [--generation value] [--target name]云目录摘要页
tiktools registry cloud-versions <id> [--target name] [--generation value] [--cursor value]云目录软件包的版本
tiktools registry cloud-pagination云目录的分页能力
tiktools registry defaults默认注册表配置

查看完整命令参考了解约定、JSON 输出和破坏性操作标记。
