组织自动化规则 ​

目标与前置条件 ​

构建小而清晰的规则库，用于响应直播事件。你需要正常运行的桌面宿主。验证上游事件需要真实的直播连接；插件操作还需要对应插件及服务就绪。

理解规则库 ​

操作 是可复用的已配置操作，例如写入日志或播放声音。事件 选择触发器、筛选条件、冷却时间及关联操作。配置将同一工作流程的定义归组；一次只能激活一个配置包。运行时变量提供可供多个操作复用的值。

  1. 打开 自动化，编辑前先确认当前配置。分别搜索事件和操作，明确自己正在选择哪类记录。
  2. 从第一条日志规则开始。先创建操作，再创建引用该操作的事件。
  3. 选择当前宿主支持的触发器。使用字段选择器为该触发器添加筛选。多个条件会缩小匹配范围，不会改变收到的载荷。
  4. 设置冷却时间及其范围。全局冷却限制所有观众对该规则的触发；按用户冷却则分别跟踪每位观众。
  5. 按顺序关联所需操作。常规模式执行选定列表，随机模式从中选择一个操作。延迟操作会推迟后续操作，不会降低直播接收速度。
  6. 保存，检查显示的定义变更，然后明确启用准备运行的记录。在运行历史中检查操作名称、结果及错误。

任何比较都可以使用值列表而不是单个值。默认组合方式为“任一”：只要有一个值匹配，条件即满足。若要求每个值都匹配，请将量词切换为“全部”——对于“不等于”，这表示“不等于其中任何一个”。条件还可以命名捕获别名：胜出的值会以 {{ match.<alias> }}（无别名时为 {{ match.<位置> }}）的形式供操作模板使用。在始终必需的条件下方，你最多可以添加四个备选：组内所有条件都必须满足，而任意一个组满足即可触发事件。

测试可能执行配置中的实际效果。按 运行测试 或触发事件前，请阅读选中的操作列表，尤其注意音频、HTTP、积分和插件操作。学习阶段请使用日志。

预期结果与状态 ​

本地编辑、执行、模板、配置及历史均可使用。插件触发器仅在对应插件已安装并启用时出现。激活状态取决于导入入口及已审核的 enabled 值；确认前应检查事件和动作。事件/操作的 更改 面板是本地参考比较，不会自动上传至 Cloud。

恢复方法 ​

没有运行记录时，依次检查当前配置、启用状态、触发器、筛选条件、冷却时间及缺失操作。发生修订冲突时，请读取当前保存的定义并重新审查，不要盲目覆盖他人的更新。大范围修改前，导出已知正常的配置。

运行细节 ​

导入或切换配置前，请阅读各入口的启用规则。切换可能启用曾单独禁用的成员。冷却状态保存在内存中，上限 24 小时；无 uniqueId 的观众共享匿名范围。保留键达到 8,192 时表会清空，因此过载或重启可能允许额外执行。它不是持久配额，也不保证阻止重放。

命令行操作 ​

本指南中的每个操作也可通过 CLI 使用——离线、可编写脚本、适合代理。用法行是解析器语法,在所有语言中保持英文。

命令摘要
tiktools automation list [--kind event&#124;action&#124;all]列出自动化规则
tiktools automation context [--event-type t]规则可用的模板上下文
tiktools automation get <id> [--kind event&#124;action]读取一条规则
tiktools automation create --record json [--kind event&#124;action]创建规则
tiktools automation update <id> --record json [--kind event&#124;action]更新规则
tiktools automation delete <id> [--kind event&#124;action]删除规则 破坏性
tiktools automation enable <id> [--kind event&#124;action]启用规则
tiktools automation disable <id> [--kind event&#124;action]禁用规则
tiktools automation test (--id <id> &#124; --record json) [--kind event&#124;action] [--trigger t] [--event json]对示例事件空跑一条规则
tiktools automation fire --trigger <type> [--event json] [--record json]手动触发触发器
tiktools automation moderation-penalty --points <delta>以积分施加管理处罚
命令摘要
tiktools workflow list列出已保存的工作流图
tiktools workflow get <id>读取一个图
tiktools workflow save --record json创建或替换图
tiktools workflow delete <id>删除图 破坏性
tiktools workflow enable <id>启用图
tiktools workflow disable <id>禁用图

查看完整命令参考了解约定、JSON 输出和破坏性操作标记。
