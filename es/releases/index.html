v4.5.2

26 nov 2026
  • Linux: the install confirmation dialog now actually appears. On 4.5.1 the confirmation was created without a parent window, and compositors with focus-stealing prevention (notably KDE Plasma) presented it behind the main window — the Install button looked dead. The dialog is now a native GTK dialog transient for the app window. The same fix applies to the plugin restart confirmation.
  • The updater now shows its outcome next to the installed version: after a restart you still see "up to date" instead of an empty area, downloads show progress inside the button itself, failed downloads offer a visible retry, and the buttons collapse to icons on narrow windows.
  • Linux: el diálogo de confirmación de instalación ahora sí aparece. En 4.5.1 se creaba sin ventana padre y compositores con prevención de robo de foco (como KDE Plasma) lo mostraban detrás de la ventana principal — el botón Instalar parecía muerto. Ahora es un diálogo GTK nativo asociado a la ventana de la app. El mismo fix aplica al diálogo de reinicio de plugins.
