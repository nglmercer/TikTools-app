Instalar y administrar plugins ​

Objetivo y requisitos ​

Añade una integración, revisa el acceso solicitado y confirma que sus acciones funcionan. Necesitas un paquete de escritorio compatible con el sistema operativo, arquitectura y versión del host exigidos por el plugin. El catálogo remoto y las descargas requieren Internet; algunos servicios también necesitan sesión de Cloud.

Revisar antes de activar ​

  1. Abre Plugins y consulta Installed, Explore o Updates. Explore solicita únicamente plugins. Las plantillas y perfiles se encuentran en Automations.
  2. Selecciona un plugin para revisar descripción, versión, compatibilidad y entorno de ejecución. Comprueba editor, capacidades y permisos; el nombre visible por sí solo no demuestra confianza.
  3. Usa el flujo de instalación para inspeccionar la vista previa del paquete. Revisa versión exacta, información de firma, acceso solicitado y diferencias respecto a la versión instalada antes de confirmar.
  4. Espera el resultado del trabajo de instalación. Descargar, instalar y activar son etapas distintas; una tarjeta del catálogo no significa que el plugin esté preparado.
  5. Abre sus paneles Settings o Connection. Introduce dirección y credenciales únicamente en los campos previstos. Usa la comprobación de conexión declarada si existe.
  6. Activa el plugin y comprueba si aparecen sus acciones o páginas. Crea una regla de registro limitada antes de vincular una acción externa potente.

Los plugins pueden ejecutar código nativo o procesos separados. Un proceso puede aislar un fallo, pero no constituye una zona aislada del sistema operativo. Instala software de editores confiables. Una firma válida identifica la procedencia del paquete revisado; no garantiza que todos sus efectos sean apropiados para tu flujo.

Resultado esperado y estado ​

Están disponibles la revisión de paquetes, los trabajos de instalación, las preferencias y la gestión de versiones. Las acciones concretas dependen del manifiesto instalado, las capacidades del host y el servicio externo. Los procesadores de eventos tienen un panel propio y pueden añadir campos de análisis opcionales; los campos originales siguen siendo distintos.

Recuperación ​

Ante un fallo, lee el error del trabajo para identificar incompatibilidad, firma, entorno o descarga. Evita debilitar la verificación para eliminar un aviso. Si una actualización falla, revisa las versiones conservadas y usa la reversión cuando esté disponible. Comprueba automatizaciones dependientes antes de desactivar o desinstalar. Conserva copias de datos y configuración antes de eliminarlos.

Operaciones de línea de comandos ​

Cada operación de esta guía también está disponible desde la CLI: sin conexión, scriptable y apta para agentes. Las líneas de uso son sintaxis del parser y permanecen en inglés en todos los idiomas.

ComandoResumen
tiktools plugin listlistar los plugins instalados

tiktools plugin uninstall <id> [--purge]desinstalar un plugin destructivo
tiktools plugin search <query> [--category c] [--page N]buscar paquetes en el registro
tiktools plugin inspect <spec>inspeccionar una especificación de paquete antes de instalar
tiktools plugin outdatedlistar los plugins instalados con actualizaciones disponibles
tiktools plugin update <id> [--version v] [--yes] [--no-wait]actualizar un plugin
tiktools plugin update --all [--yes] [--no-wait]actualizar todos los plugins desactualizados
tiktools plugin rollback <id> [version] [--no-wait]volver a una versión anterior destructivo
tiktools plugin versions <id>listar las versiones disponibles de un plugin
tiktools plugin pin <id>fijar un plugin a su versión actual
tiktools plugin unpin <id>quitar la fijación de versión
tiktools plugin policy <id> [--channel stable&#124;beta] [--auto off&#124;notify&#124;patch&#124;minor]establecer el canal y la política de autoactualización
tiktools plugin jobslistar los trabajos de paquetes
tiktools plugin job <job-id>inspeccionar un trabajo de paquete

tiktools plugin start <id>iniciar un plugin
tiktools plugin stop <id>detener un plugin destructivo

tiktools plugin health <id>comprobación de salud de un plugin
