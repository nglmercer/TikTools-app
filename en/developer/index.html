Develop TikTools ​

TikTools keeps one native AppCore behind typed control operations. Vue renders the desktop, local-browser and controller interfaces; Winit/Wry owns desktop windows. The CLI and SDK use the same operations. Start with the development setup, then choose the smallest loop that covers your change.

Choose an entry point ​

WorkEntry pointWhat it establishes
Vue components and storesVite, Vitest and the injected ControlClientInterface behavior; no native window validation.
Desktop integrationbun run startDevelopment WebView and IPC integration.
Native servicesTargeted Cargo testsCore contracts, persistence and service behavior.
Headless browser accessbun run devA native host, local adapter and Vite with pairing.
Documentationbun scripts/task.ts docs devMarkdown, VitePress and the demo dev server for embedded demos.
Public demoSeparate demo entry and simulated transportFictional deterministic scenarios, not upstream services.

Source ownership ​

  • crates/tiktools-core: services, operations and SQLite. It does not depend on a WebView.
  • crates/tiktools-control-api: registry, JSON-RPC routing, IPC and discovery.
  • crates/tiktools-desktop: Winit/Wry, UI-thread bridge, lifecycle and packaged assets.
  • src/web/app: bootstrap, router and shell. pages compose widgets and features; entities own domain stores/contracts; shared holds reusable UI and infrastructure.
  • src/automation/contracts/generated: versioned frontend event contracts generated from Rust. Do not retype these schemas in a demo or guide.
  • packages: the existing TypeScript plugin SDK/UI packages. Plugin implementations live in the external plugins repository.

Contribution boundary ​

Keep native, local-browser, remote-controller and demo entry points explicit. Absence of a native host is an error in a real entry point; it must not silently select a mock. Dispose listeners, subscriptions and timers with the owning scope. Keep Rust/Bun lockfiles and required CI gates intact.

User installation belongs in the user guide. These development checks do not establish real TikTok connectivity, OBS rendering, native WebView compatibility or two-computer collaboration by themselves.
