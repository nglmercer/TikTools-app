実行時変数の再利用と変更の確認 ​

目的と前提条件 ​

共有値を一度変更し、複数のアクションで再利用します。自動化 → 変数 と、対象の変数操作に対応するホストが必要です。型付き編集や確認を伴う Cloud 操作はホスト機能に応じて表示されます。ローカル保存にアップロードは不要です。

ローカル値を保存する ​

  1. showLabel という変数を追加します。キーは英字かアンダースコアで始め、英数字、ドット、アンダースコア、ハイフンを含められます。上限は 64 文字です。キーの重複を避けます。
  2. 型付き編集が利用できる場合、テキストを選び 夜の配信 と入力します。他に数値、真偽値、リスト、シークレットを利用できます。リストは ["赤", "青"] などの文字列の JSON 配列です。
  3. グローバル変数を保存 を選びます。リビジョン競合は保存済みコレクションが変わったことを意味するため、再読み込みして変更内容を照合します。
  4. テンプレート対応のアクション欄で保存値を使います。
text
{{ globals.showLabel }}: {{ event.user.uniqueId }}
  1. ログだけのアクションをテストして展開後のテキストを確認します。showLabel を変更して保存し、もう一度テストします。テンプレートを再インポートしなくても既存アクションは更新された値を使えます。

テンプレートの params は適用時に置換され、globals は実行時に読まれます。存在しない実行時キーは空文字になるため、送信先や識別子で使う前に綴りを確認してください。イベントのパスは各フィールドの変数候補からトリガーに合うものを選びます。

条件は一致ごとの値を公開することもできます。フィルターがキャプチャエイリアスを宣言すると、それを満たした値はイベントのアクションのレンダリング中に {{ match.<alias> }}（エイリアスがなければ {{ match.<位置> }}）として使えます。例えば、コメントへの「で始まる」条件に prefix というエイリアスを付けると、ログアクションで {{ match.prefix }} を出力できます。キャプチャは上限付きのプレーンテキストで、実際に一致したフィルターと代替だけが生成し、クールダウンキーは変わりません。

テンプレート対応フィールドの + を押すと 変数を挿入 が開き、右側に正確なパスが表示され、行を選ぶと {{ パス }} がフィールドに追加されます。このイベントのキャプチャも一覧に表示されますが、対応する条件が一致した場合にのみ解決されます。{{ match.<alias> }} を使うには、条件セクションでエイリアスを設定してください（下部の キャプチャ ボタンでエイリアス欄を表示します）。設定しない場合は位置 {{ match.<位置> }} を使います。

Cloud の変更は別途確認する ​

変数の 変更 では、対応ホスト上で送信、取得、適用・採用、取り下げを確認付きで実行できます。先にローカル編集を保存し、比較を選び、型と値を確認して方向を明示的に選びます。Cloud 候補の取得とローカル適用は別操作です。共有値の取り下げとローカル行の削除も異なります。

シークレットや送信禁止の値は比較でマスクされ、この経路では送信できません。制限を回避するためにシークレットを通常テキストに変えないでください。

期待される結果・提供状況と対処 ​

ローカル変数と、ホスト機能に応じた確認付き共有を利用できます。ローカル保存で自動アップロードは行われません。不正なキー、型に合わない値、古いリビジョンでは保存できません。強調された欄を修正するか、再読み込みしてから再試行します。アカウントの問題は Cloud アカウント、比較の動作は 変更 を参照してください。

コマンドライン操作 ​

このガイドのすべての操作はCLIからも利用できます——オフライン、スクリプト可能、エージェント対応。使用法の行はパーサー構文であり、すべての言語で英語のままです。

コマンド概要
tiktools globals listすべてのグローバルキーを一覧表示
tiktools globals get <key>グローバルを1つ読み取る
tiktools globals set <key> <value>グローバルを1つ書き込む
tiktools globals delete <key>グローバルを1つ削除 破壊的

規約、JSON出力、破壊的操作のマーカーについては完全なコマンドリファレンスを参照してください。
