自動化を整理する ​

目的と前提条件 ​

LIVE のイベントに反応する、小さく分かりやすいライブラリを作ります。正常に動くデスクトップホストが必要です。配信元のイベントの検証には実際の LIVE 接続 が、プラグインのアクションには対応するプラグインとサービスの準備も必要です。

ライブラリの仕組み ​

アクション はログ出力や音の再生など、設定を再利用できる処理です。イベント はトリガー、フィルター、クールダウン、関連アクションを指定します。プロファイルは用途ごとに定義をまとめ、一度に有効になるプロファイルパックは1つです。実行時の変数 を使うと、複数のアクションで値を共有できます。

  1. 自動化 を開き、編集前にアクティブなプロファイルを確認します。イベントとアクションは別々に検索し、選ぶレコードの種類を把握します。
  2. 最初のログ記録ルール から始めます。先にアクションを作り、それを参照するイベントを作成します。
  3. 現在のホストが対応するトリガーを選び、フィールド選択から対応するフィルターを追加します。複数条件は一致範囲を絞りますが、受信ペイロードは変更しません。
  4. クールダウンと適用範囲を設定します。全体のクールダウンは全視聴者を通じてルールを制限し、ユーザー別では視聴者ごとに管理します。
  5. 目的のアクションを順に関連付けます。通常モードは選んだ一覧を実行し、ランダムモードはその中から1つ選びます。遅延アクションは後続処理を遅らせますが、LIVE の取り込みは遅らせません。
  6. 保存して表示された定義の変更を確認し、実行するレコードを明示的に有効にします。履歴でアクション名、結果、エラーを確認します。

すべての比較で単一の値の代わりに値のリストを指定できます。既定の結合は「いずれか」で、少なくとも1つの値が一致すれば条件を満たします。すべての値の一致が必要な場合は量指定子を「すべて」に変更します。「ではない」の場合は「どれでもない」と読みます。条件にはキャプチャエイリアスも付けられ、勝った値はアクションテンプレートで {{ match.<alias> }}（エイリアスがなければ {{ match.<位置> }}）として使えます。常に必須の条件の下に、最大4つの代替を追加できます。各グループ内の条件はすべて満たす必要があり、いずれか1つのグループが満たされればイベントは発火します。

テストでも設定した処理が実行されます。特に音声、HTTP、ポイント、プラグインでは、テストを実行 やイベント実行の前に選択中のアクション一覧を読んでください。学習中はログを使います。

期待される結果と提供状況 ​

ローカル編集、実行、テンプレート、プロファイル、履歴を利用できます。プラグインのトリガーは対応プラグインがインストールされ有効な間だけ表示されます。有効状態はインポート経路と確認済み enabled 値によります。確定前にイベントとアクションを確認してください。イベント／アクションの 変更 はローカルの基準との比較 であり、Cloud への自動アップロードではありません。

問題が起きたとき ​

実行されない場合は、アクティブなプロファイル、有効状態、トリガー、フィルター、クールダウン、欠けたアクションの順に確認します。リビジョンが競合したら、現在の保存済み定義を読み直して再確認します。他の人の更新を無条件に上書きしないでください。大きな変更の前に、正常なプロファイル をエクスポートします。

運用の詳細 ​

取り込み・切り替え前に経路ごとの有効化規則を読みます。個別に無効化した項目も再び有効になる場合があります。cooldown はメモリ内で最大 24 時間、uniqueId 不在の視聴者は匿名範囲を共有します。保持キー 8,192 件で表を空にするため、過負荷や再起動で追加実行が起こり得ます。永続 quota・replay 保証ではありません。

コマンドライン操作 ​

このガイドのすべての操作はCLIからも利用できます——オフライン、スクリプト可能、エージェント対応。使用法の行はパーサー構文であり、すべての言語で英語のままです。

コマンド概要
tiktools automation list [--kind event&#124;action&#124;all]自動化ルールを一覧表示
tiktools automation context [--event-type t]ルールで利用可能なテンプレートコンテキスト
tiktools automation get <id> [--kind event&#124;action]ルールを1つ読み取る
tiktools automation create --record json [--kind event&#124;action]ルールを作成
tiktools automation update <id> --record json [--kind event&#124;action]ルールを更新
tiktools automation delete <id> [--kind event&#124;action]ルールを削除 破壊的
tiktools automation enable <id> [--kind event&#124;action]ルールを有効化
tiktools automation disable <id> [--kind event&#124;action]ルールを無効化
tiktools automation test (--id <id> &#124; --record json) [--kind event&#124;action] [--trigger t] [--event json]サンプルイベントに対してルールをドライラン
tiktools automation fire --trigger <type> [--event json] [--record json]トリガーを手動で発火
tiktools automation moderation-penalty --points <delta>ポイントでモデレーションペナルティを適用
コマンド概要
tiktools workflow list保存されたワークフローグラフを一覧表示
tiktools workflow get <id>グラフを1つ読み取る
tiktools workflow save --record jsonグラフを作成または置換
tiktools workflow delete <id>グラフを削除 破壊的
tiktools workflow enable <id>グラフを有効化
tiktools workflow disable <id>グラフを無効化

規約、JSON出力、破壊的操作のマーカーについては完全なコマンドリファレンスを参照してください。
