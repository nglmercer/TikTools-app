テンプレートのインポートとプロファイルの管理 ​

目的と前提条件 ​

確認済みのルールやルール集を、誤って実行せずに再利用します。自動化、信頼できる JSON ファイルまたはカタログ項目、アクションが必要とするプラグインを用意します。既存の構成を置き換える前に、現在のプロファイルをエクスポートしてください。

適切な操作画面を選ぶ ​

.tiktemplate.json は1つのイベントとそのアクションを記述し、.tikprofile.json は複数のテンプレートをまとめます。組み込み・カスタムテンプレート、Cloud ライブラリ、手動テンプレートインポートは自動化のテンプレートダイアログで開きます。プロファイルの作成、選択、エクスポート、手動インポートはプロファイルツールバーを使います。プラグイン → 探す はプラグインを探す画面で、テンプレートとプロファイルはこちらで扱います。

確認してインポートする ​

  1. 対象のインポートダイアログを開き、ファイルを選ぶか、対応する JSON を貼り付けます。続行前に準備された名前と出所を確認します。
  2. テンプレートではトリガー、アクション種別、パラメーターを確認します。プロファイルでは項目数と共通パラメーターも確認します。
  3. 例の送信先、メディアパス、視聴者識別子を自分の構成に合う値に置き換えます。共有用ファイルに認証情報を貼り付けないでください。
  4. 適用・インポートを明示的に実行して結果を待ちます。定義が無効とは限りません。レビューの enabled 値を確認します。後で選択し、各アクションとイベントを確認して必要なものだけを明示的に有効化します。
  5. まずログだけのテストをするか、定義を確認します。HTTP、音声、ポイント、プラグインのテストでは実際の処理が動きます。
  6. 確定前に移動先メンバーの有効化とその他の無効化を確認します。単独レコードや以前無効にした移動先も対象です。効果は trigger・条件が必要で、Cloud sync ではありません。

{{ params.giftName }} などのパラメーターはテンプレート適用時に解決されます。{{ event.user.uniqueId }} などの実行時参照は各イベントのために残り、グローバル変数 は実行時に保存済みの共有値を提供します。

期待される結果と提供状況 ​

ローカルのテンプレート・プロファイルの入出力を利用できます。Cloud の閲覧には対応するホスト機能とアカウント・サービスが必要です。カタログのプレビューだけでは外部サービスの動作は確認できません。必要なプラグインがなければ、インストールと設定が済むまで取り込んだ定義を使えない場合があります。

問題が起きたとき ​

無効な JSON はパーサーのエラーと期待される文書形式を確認します。任意の JSON の名前を変えても形式は変換されません。リビジョン競合では保存済みライブラリを更新してから再適用します。正常なプロファイルの書き出しを保持し、含まれないデータについてはバックアップ を参照してください。

運用の詳細 ​

手動テンプレート import はまずカタログ文書を保存し、適用で関連アクション・イベントを作ります。enabled 省略時の parser 既定は true で、適用も値を保持します。手動プロファイル import も項目を所有者レビューへ渡します。Cloud カタログはテンプレートを保存し、Cloud プロファイルは来歴付き変更を準備します。出所・プレビュー成功だけで一律無効とは保証できません。最終比較と保存状態を確認します。CLI では明示的に tiktools template import file.tiktemplate.json --disabled または tiktools template profile-import file.tikprofile.json --disabled を使います。

プロファイル切り替えは有効状態を変えます。確定すると移動先の全メンバーを有効化し、その他すべてのアクション・イベント（単独項目を含む）を無効化します。以前無効にした移動先メンバーも有効になる場合があります。両方のリストを確認します。副作用にはトリガー・条件・利用可能 runtime が必要で、切り替え自体は Cloud 同期を送りません。

コマンドライン操作 ​

このガイドのすべての操作はCLIからも利用できます——オフライン、スクリプト可能、エージェント対応。使用法の行はパーサー構文であり、すべての言語で英語のままです。

コマンド概要
tiktools template import <file> [--param k=v]... [--event-name n] [--action-name n] [--dry-run] [--no-save] [--disabled]テンプレートを自動化ルールとしてインポート
tiktools template export --event <id> --out <file> [--title t] [--id template-id]イベントルールをテンプレートとしてエクスポート
tiktools template listギャラリーのテンプレートを一覧表示
tiktools template delete <template-id>テンプレートを削除 破壊的
tiktools template profile-import <file> [--param k=v]... [--dry-run] [--no-save] [--disabled]自動化プロファイル全体をインポート
tiktools template profile-export --out <file> [--name n]自動化プロファイルをエクスポート

規約、JSON出力、破壊的操作のマーカーについては完全なコマンドリファレンスを参照してください。
