TikTools 4.2.1-rc.3 (Linux)

13 de nov. de 2026
  • Retains RC2's correction for concurrent Changes/conflict reads and its local retry with the native failure reason.
  • Variables now persist explicit text, number, boolean, list and local-secret types. Saves are atomic and reject a changed host or stale editor revision. Existing text rendering in automation templates remains compatible.
  • A secret stays masked in the editor and never falls back to a legacy write after switching hosts. Native classification also blocks publication of values queued before the variable became secret; Changes projections omit those values. Saving Variables remains local.
