Installer et gérer les plugins ​

Objectif et prérequis ​

Ajouter une intégration, examiner les accès demandés et confirmer que ses actions sont utilisables. Il faut un paquet de bureau compatible avec le système d’exploitation, l’architecture et la version d’hôte du plugin. Les opérations de catalogue distant et de téléchargement nécessitent un accès réseau ; certains services liés au compte nécessitent aussi une connexion Cloud.

Examiner avant d’activer ​

  1. Ouvrez Plugins et examinez Installed, Explore ou Updates. Explore demande uniquement des entrées de plugins. Les modèles et profils d’automatisation se trouvent dans Automations.
  2. Sélectionnez un plugin pour examiner sa description, sa version, sa compatibilité et son environnement d’exécution. Vérifiez l’éditeur et les capacités ou permissions demandées plutôt que de vous fier uniquement à un nom familier.
  3. Utilisez le parcours d’installation pour examiner l’aperçu du paquet. Examinez la version exacte, les informations de signature, les accès demandés et les différences avec une version installée avant de confirmer l’installation.
  4. Attendez le résultat de la tâche de paquet. Téléchargement, installation et activation sont des étapes distinctes ; une fiche de catalogue seule ne signifie pas que l’environnement d’exécution est prêt.
  5. Ouvrez le volet Settings ou Connection du plugin. Fournissez l’adresse de son service et ses identifiants uniquement dans les champs prévus. Utilisez la vérification de connexion déclarée lorsqu’elle est proposée.
  6. Activez le plugin, puis vérifiez l’apparition de ses types d’action ou pages. Créez une règle de journalisation ciblée avant d’attacher une action externe puissante.

Les plugins peuvent exécuter du code natif ou des processus séparés. Une frontière de processus peut isoler un plantage, mais ne constitue pas un bac à sable du système d’exploitation. Installez des logiciels provenant d’éditeurs de confiance. Une signature valide identifie la provenance vérifiée d’un paquet ; elle ne rend pas chaque effet approprié à votre usage.

Résultat attendu et état ​

L’examen des paquets, les tâches d’installation, les préférences de plugins et la gestion des versions sont disponibles. Les actions réelles dépendent du manifeste installé, des capacités de l’hôte et du service externe. Les processeurs d’événements ont leur propre panneau et peuvent ajouter des champs d’analyse facultatifs aux événements ; les champs bruts restent distincts.

Récupération ​

En cas d’échec d’installation, lisez l’erreur de tâche pour identifier un problème de compatibilité, signature, exécution ou téléchargement. N’affaiblissez pas la vérification simplement pour effacer l’erreur. Si une mise à jour pose problème, examinez les versions conservées et utilisez le retour arrière lorsqu’il est disponible. Examinez les automatisations dépendantes avant de désactiver ou désinstaller un plugin. Gardez des sauvegardes des données et configurations des plugins avant de les supprimer.

Démo : pluginsdemo:plugins

Opérations en ligne de commande ​

Chaque opération de ce guide est aussi disponible depuis la CLI — hors ligne, scriptable et adaptée aux agents. Les lignes d'usage sont la syntaxe du parseur et restent en anglais dans toutes les langues.

CommandeRésumé
tiktools plugin listlister les plugins installés
tiktools plugin get <id>lire un plugin
tiktools plugin install <file.plugin> [--replace] &#124; plugin install <id[@version]&#124;url> [--yes] [--no-wait] [--allow-unsigned]installer depuis un fichier, id@version ou url
tiktools plugin uninstall <id> [--purge]désinstaller un plugin destructif
tiktools plugin search <query> [--category c] [--page N]rechercher des paquets dans le registre
tiktools plugin inspect <spec>inspecter une spécification de paquet avant installation
tiktools plugin outdatedlister les plugins installés avec des mises à jour disponibles
tiktools plugin update <id> [--version v] [--yes] [--no-wait]mettre à jour un plugin
tiktools plugin update --all [--yes] [--no-wait]mettre à jour tous les plugins obsolètes
tiktools plugin rollback <id> [version] [--no-wait]revenir à une version précédente destructif
tiktools plugin versions <id>lister les versions disponibles d'un plugin
tiktools plugin pin <id>épingler un plugin à sa version actuelle
tiktools plugin unpin <id>retirer l'épinglage de version
tiktools plugin policy <id> [--channel stable&#124;beta] [--auto off&#124;notify&#124;patch&#124;minor]définir le canal et la politique de mise à jour automatique
tiktools plugin jobslister les travaux de paquets
