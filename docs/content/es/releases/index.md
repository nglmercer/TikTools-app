# Versiones y canales {#releases-and-channels}

Consulta las notas antes de cambiar de versión. La lista de GitHub distingue las versiones publicadas, estables y preliminares. Una etiqueta de código no garantiza que sus instaladores ya estén publicados.

<ReleaseList />

<DocCallout title="Elige el paquete para tu equipo" tone="tip">

Comprueba el sistema operativo, la arquitectura y el tipo de paquete antes de descargar. Las tarjetas muestran los archivos publicados cuando se consultó GitHub; abre las notas de la versión para comprobar cambios, requisitos y descargas posteriores. Conserva una copia de tus datos antes de actualizar.

</DocCallout>
