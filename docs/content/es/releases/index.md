# Versiones y canales

Consulta las notas antes de cambiar de versión. La lista de GitHub distingue las versiones publicadas, estables y preliminares. Una etiqueta de código no garantiza que sus instaladores ya estén publicados.

- [Versiones publicadas](https://github.com/nglmercer/TikTools-app/releases)
- [Actualización e instalación](../user/updates.md)
- [Código de 4.2.2](https://github.com/nglmercer/TikTools-app/tree/v4.2.2)

Los candidatos 4.2.1 conservaron evidencia de la recuperación de Cloud y del empaquetado Linux. Sus registros originales permanecen en el archivo interno; no prueban el funcionamiento de todos los servicios ni sustituyen una prueba del paquete que se descargue.
