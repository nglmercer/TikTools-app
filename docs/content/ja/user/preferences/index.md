# 設定とキーボード操作を見つける {#find-preferences-and-keyboard-controls}

## 目的と前提条件 {#goal-and-prerequisites}

アプリの言語と正しい設定場所を見つけ、対応キーボード操作を快適に使います。デスクトップウィンドウを開いておく必要があります。ネットワークは設定するサービスが必要とする場合だけ使います。

## 対象の設定を探す {#find-the-relevant-setting}

1. **設定 → 一般** で表示言語を選びます。現在は英語 (`en`)、スペイン語 (`es`)、ポルトガル語 (`pt`)、フランス語 (`fr`)、簡体字中国語 (`zh`)、日本語 (`ja`) です。言語選択で TikTok イベント識別子やプラグイン API 名は変わりません。
2. 一般の更新設定で、チャンネル、自動確認、通知、対応時の手動確認を調べます。自動確認は任意です。署名付き更新の可否は、そのビルドで公開された署名設定に依存します。
3. **アカウント** で Cloud ID と診断、**共同作業** で所有者のアクセス、ホストが対応する場合は **チーム** を使います。
4. **プラグイン** で共通設定と各プラグインの設定/接続を開きます。プラグインのサービス認証情報は一般には入力しません。
5. 共有実行時値は **自動化 → 変数**、付与ルールは **ポイント**、ウィジェット設計は **オーバーレイ** にあります。影響する機能の近くに配置されています。

自動インストールは実験段階で、現行リリースのビルド条件により無効です。自動確認の設定が見えても自動インストールを約束しません。[更新手順](../updates.md) に従い、版の変更前に[バックアップ](backups.md) を取ります。

## 対応するキーボード操作を使う {#use-supported-keyboard-controls}

Tab と Shift+Tab で通常の操作欄間を移動し、Enter/Space でフォーカス中のボタンを実行します。オーバーレイのデザインインスペクターでは Ctrl/Meta+Z で元に戻し、Ctrl/Meta+Shift+Z または Ctrl/Meta+Y でやり直します。テキスト入力は独自の取り消しを維持します。これは編集用で、全体の自動化ホットキーではありません。

他の操作が処理していなければ Escape で狭幅のナビゲーションを閉じます。ダイアログやエディターは未保存確認などのため独自に Escape を扱う場合があります。グローバルホットキーの自動化には、互換プラグインと通知されたバックエンド機能が必要です。

## 期待される結果・提供状況と対処 {#expected-result-status-and-recovery}

これらの設定とローカルキーボード操作を利用できますが、アクセシビリティや各環境の完全な適合は主張しません。ラベル付きボタン、読みやすいウィンドウサイズを使い、動きが気になるならフィードを停止します。設定が見えなければリセット前に担当ページとホスト機能を確認します。操作不能は[トラブルシューティング](troubleshooting.md)、よくある違いは [FAQ](faq.md) を参照します。
