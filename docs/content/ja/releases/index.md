# リリースとチャンネル {#releases-and-channels}

使用する OS に対応した公開済みパッケージを選び、更新前にリリースノートを確認してください。下のカードは安定版とプレリリースを区別し、リリース情報のスナップショットに記録されたダウンロードファイルを表示します。

<ReleaseList />

<DocCallout title="ソースのタグとインストーラーは別です" tone="info">

ソースのタグだけでは、インストーラーの公開を確認できません。取得する前に、利用可能なファイルと対象 OS を確認してください。スナップショットには確認日が付いています。それ以降の変更や現在のリリース一覧は GitHub で確認できます。

</DocCallout>
