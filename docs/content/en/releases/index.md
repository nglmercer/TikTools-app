# Releases and channels {#releases-and-channels}

Choose a published package for your operating system and read its release notes before updating. The cards below distinguish stable releases from prereleases and show the downloadable files recorded in the release snapshot.

<ReleaseList />

<DocCallout title="A source tag is not an installer" tone="info">

A source tag does not establish that its installers have already been published. Check the available assets and their platform before downloading. The snapshot has a verification date; open GitHub for the current release list and any changes since that date.

</DocCallout>
