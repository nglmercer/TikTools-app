# Releases and channels

Read the notes before changing versions. GitHub distinguishes published stable releases and prereleases. A source tag does not establish that its installers have already been published.

- [Published releases](https://github.com/nglmercer/TikTools-app/releases)
- [Updating and installation](../user/updates.md)
- [4.2.2 source](https://github.com/nglmercer/TikTools-app/tree/v4.2.2)

The 4.2.1 candidates retain evidence of Cloud recovery and Linux packaging. Their original records remain in the internal archive; they do not establish every external service or replace verification of the package you download.
