# Versões e canais {#releases-and-channels}

Leia as notas antes de mudar de versão. O GitHub distingue versões estáveis publicadas e versões preliminares. Uma tag de código-fonte não comprova que seus instaladores já foram publicados.

<ReleaseList />

<DocCallout title="Escolha o pacote do seu sistema" tone="tip">

Confira o canal, as notas e os arquivos publicados para a versão desejada. Use o instalador ou o pacote portátil adequado ao seu sistema e confira os checksums quando disponíveis.

</DocCallout>

- [Versões publicadas](https://github.com/nglmercer/TikTools-app/releases)
- [Atualização e instalação](../user/updates.md)
- [Código-fonte 4.2.2](https://github.com/nglmercer/TikTools-app/tree/v4.2.2)

As candidatas 4.2.1 mantêm evidências de recuperação do Cloud e empacotamento Linux. Seus registros originais permanecem no arquivo interno; eles não comprovam todos os serviços externos nem substituem a verificação do pacote baixado.
