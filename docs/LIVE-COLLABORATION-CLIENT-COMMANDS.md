# Remote commands and durable recovery / Comandos remotos y recuperación duradera

This legacy URL is retained. Use the topic guides below for current instructions.

Se conserva esta dirección antigua. Usa las guías temáticas siguientes para las instrucciones actuales.

**Status / Estado:** experimental or incomplete; verify the limits in the current guide / experimental o incompleto; revisa los límites de la guía actual.

**Source review:** Native and browser controller journals are separate implementations. The browser workflow recovery code is bounded and identity-bound; neither reconnection nor a retained receipt authorizes replaying an unknown command as a new one.

**Revisión del código:** Los diarios nativos y del navegador son implementaciones separadas. La recuperación de flujos del navegador es limitada y está ligada a la identidad; reconectar o conservar un recibo no autoriza repetir un comando incierto con otro identificador.
